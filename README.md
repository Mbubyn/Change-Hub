# Change Hub

A self-hosted, white-label e-learning platform for Change Management practitioners. Fork it, customize it, deploy it — no vendor licence required.

## What it is

The Change Hub is an interactive knowledge base and toolkit for anyone involved in leading, planning, supporting, or implementing organizational change. The Government of Canada version ships as the reference implementation. Any organization can fork this repo and deploy their own branded version.

**Features:**
- 14 content pages across 3 learning sections
- 5 interactive component types: tabs, flip cards, accordions, carousels, and hotspot maps
- Filterable toolkit resource library (powered by Airtable or a local CSV dashboard)
- 96+ downloadable CM tools and templates
- Fully static — runs on GitHub Pages, works inside firewalls, no server required

## Deploy your own

See [DEPLOYING.md](DEPLOYING.md) for a step-by-step guide to forking and customizing this for your organization.

## Tech

Vanilla HTML, CSS, and JavaScript. No framework. No build step. Open `index.html` in a browser and it works.
