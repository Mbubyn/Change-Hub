# Stage 5 — Toolkit

## Goal
Build the toolkit resource hub: the Airtable-powered filterable dashboard and the 96-item document download page. This is the feature learners return to most.

## Features in this stage
- `feature-airtable-embed.md` — Airtable iframe integration for the toolkit dashboard
- `feature-toolkit-downloads.md` — 96-item document download page rendered from `toolkit.csv`

## Definition of done
- [ ] Toolkit page loads and renders the Airtable iframe correctly
- [ ] All 96 download links are present and working
- [ ] Document list is generated from `toolkit.csv` (not hardcoded HTML)
- [ ] Page is usable without Airtable (graceful fallback or note if iframe blocked)
- [ ] Toolkit data in `toolkit.csv` is complete and accurate
