# Stage 1 — Foundation

## Goal
Build a working shell: a navigable static site with the correct sidebar structure and client-side routing. No real content yet — just the skeleton that all future stages will fill.

## Features in this stage
- `feature-sidebar-nav.md` — 3-section sidebar with all 14 page links, active state, collapsible sections
- `feature-routing.md` — hash-based client-side routing, page load/swap logic
- `feature-base-template.md` — HTML shell, CSS design tokens, base layout (sidebar + content pane)

## Definition of done
- [ ] All 14 pages are navigable via the sidebar
- [ ] Active page is highlighted in the sidebar
- [ ] Sidebar sections collapse/expand
- [ ] Content pane renders a placeholder for each page
- [ ] No CDN dependencies — all assets local
- [ ] Opens correctly as a static file (`index.html`) without a server
- [ ] Looks visually close to the Rise original (colors, fonts, layout proportions)
